# Hair Center of Turkey — Concept Redesign

An **unofficial concept redesign** of a hair-transplant clinic landing page, built as a
permissionless-apprenticeship demonstration by **Alperen Muti**. Not affiliated with, or
endorsed by, Hair Center of Turkey. All stats, results and reviews shown are illustrative
placeholders for design purposes only.

A flashy, animated, dark-premium marketing site built with **Next.js 16 + React 19 +
Tailwind v4 + Magic UI**.

## Magic UI components used

`retro-grid` · `particles` · `meteors` · `aurora-text` · `animated-gradient-text` ·
`text-animate` · `shimmer-button` · `border-beam` · `shine-border` · `marquee` ·
`number-ticker` · `bento-grid` · `globe` · `orbiting-circles` · `animated-beam` · `blur-fade`

## Sections

Hero (retro-grid + particles + aurora headline) → trust marquee → animated stat counters →
bento feature grid (with orbiting badges & vertical marquee) → real-results before/after
(shine-border) → interactive globe of 50+ countries → animated-beam lead-routing process →
testimonials marquee → CTA with border-beam.

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm run start
```

## Stack

Next.js 16 (App Router, Turbopack) · React 19 · TypeScript · Tailwind CSS v4 ·
shadcn + Magic UI · Sora display font.
